# 셀로맥스사이언스 홈페이지 운영 매뉴얼

## 1. 관리자 페이지 접속

- **URL**: `https://cellromax-website.vercel.app/ko/admin/login`
- **접속 방법**: URL을 직접 입력하여 접속 (공개 메뉴에는 노출되지 않음)
- **로그인 잠금**: 5분 내 5회 연속 실패 시 자동 잠금

---

## 2. 제품 관리

### 2-1. 제품 등록

1. 관리자 페이지 > 사이드바 **"제품 관리"** 클릭
2. 우측 상단 **"제품 등록"** 버튼 클릭
3. 필수 입력 항목:
   - **제품명** (한국어 필수, 영어/중국어/베트남어 선택)
   - **카테고리** (건강기능식품, 일반의약품, 의약외품, 기타)
   - **하위카테고리** 선택
   - **썸네일 이미지** (권장: 800x800px, WebP/PNG/JPG, 10MB 이하)
   - **제품 설명** (다국어)
4. 선택 입력 항목:
   - 갤러리 이미지 (복수 업로드 가능)
   - 상세페이지 HTML
   - 영양정보 이미지
   - 섭취량, 섭취방법, 기타정보, 주의사항, 보관방법
5. **"저장"** 버튼 클릭

### 2-2. 제품 수정/삭제

- 제품 목록에서 해당 제품의 **"수정"** 아이콘 클릭 > 내용 수정 후 저장
- **삭제**: Super Admin 계정만 가능

### 2-3. 제품 활성/비활성

- 제품을 삭제하지 않고 **비활성화**하면 프론트에서 숨겨짐
- 제품 수정 페이지에서 `활성 상태` 토글로 제어

---

## 3. 게시판 관리 (공지사항 / 회사소식 / 홍보영상)

### 3-1. 게시글 작성

1. 사이드바 **"게시판 관리"** 클릭
2. **"게시글 작성"** 버튼 클릭
3. 입력 항목:
   - **카테고리** 선택 (공지사항 / 뉴스 / 홍보영상)
   - **제목** (다국어)
   - **내용** (리치텍스트 에디터)
   - 홍보영상의 경우 **YouTube URL** 입력
   - **첨부파일** (선택, 복수 업로드 가능)
4. **"저장"** 클릭

### 3-2. 게시글 수정/삭제

- 목록에서 해당 게시글 클릭 > 수정 후 저장
- 삭제는 비활성화로 대체 권장

---

## 4. IR 자료 관리

### 4-1. IR 파일 업로드

1. 사이드바 **"IR 관리"** 클릭
2. **"IR 자료 등록"** 버튼 클릭
3. 입력 항목:
   - **제목** (다국어)
   - **카테고리** (사업보고서, 감사보고서, 공시자료)
   - **연도** 선택
   - **PDF 파일** 업로드 (50MB 이하)
4. **"저장"** 클릭

---

## 5. 약국 CSV 일괄 업로드

### 5-1. CSV 파일 형식

```csv
name,address,phone,latitude,longitude
서울중앙약국,서울시 중구 명동길 12,02-1234-5678,37.5665,126.9780
```

### 5-2. 업로드 방법

1. 사이드바 **"약국 관리"** 클릭
2. **"CSV 업로드"** 버튼 클릭
3. 준비된 CSV 파일 선택
4. 미리보기 확인 후 **"업로드"** 클릭

---

## 6. 문의 관리

1. 사이드바 **"문의 관리"** 클릭
2. 접수된 문의 목록 확인 (소비자 / 약사 / 비즈니스 탭)
3. 문의 클릭하여 상세 내용 확인
4. **상태 변경**: 접수 > 처리중 > 완료
5. **관리자 메모** 작성 가능

---

## 7. 계정 관리 (Super Admin 전용)

1. 사이드바 **"계정 관리"** 클릭
2. **"계정 추가"** 버튼으로 새 관리자 생성
3. 역할 종류:
   - **super_admin**: 모든 권한
   - **marketing**: 제품, 게시판, 약국 관리
   - **ir**: IR 자료 관리
   - **inquiry**: 문의 관리
4. 계정 비활성화: 해당 계정의 토글 Off

---

## 8. 보안 주의사항

- 관리자 URL은 외부에 공유하지 마세요
- 비밀번호는 8자 이상, 주기적으로 변경하세요
- 사용하지 않는 계정은 비활성화하세요
- 공용 PC에서 로그인 후 반드시 로그아웃하세요

## 9. 기술 지원

- **배포 플랫폼**: Vercel (자동 배포, GitHub 연동)
- **데이터베이스**: Supabase (PostgreSQL)
- **이미지/파일 저장**: Supabase Storage
- **이메일 발송**: Resend
- **지도**: 카카오맵 API

### Vercel 재배포 방법
GitHub main 브랜치에 커밋 push 시 자동 배포됩니다.

### 환경변수 관리
Vercel 대시보드 > Settings > Environment Variables에서 관리합니다.
변경 후 재배포 필요합니다.
